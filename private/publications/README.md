# Encrypted Digital Publications

Upload only the encrypted files `abstracts.enc`, `english.enc` and `hindi.enc` here. These are encrypted using AES-256-GCM; the decryption key is stored only in the Vercel production environment, not in the repository.

**Never commit plaintext PDFs, private keys, or attendee data to this folder.**

The server-side publication endpoint blocks downloads until 16 October 2026 at 09:30 hrs IST.
